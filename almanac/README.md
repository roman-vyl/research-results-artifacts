# Альманах книжных метрик отката

`almanac.html` — альманах «Как работает каждая книжная метрика» (поток «Второе мнение: фильтры отката»). Это снимок опубликованной страницы https://claude.ai/artifact/NrNTEUnqzqJxbmoHHPiNV4 от 2026-10-11 (версия 5). В нём переписан раздел A1: Δ со знаком (EMA5 − EMA якоря), последние 75 баров каждой ноги. B1 заменена принятой версией владельца: самая большая свеча против сделки на откате ÷ самая большая свеча по сделке на импульсе (каждая в ATR своего ТФ; 5m, 15m, 1h; отрез сверху), книжная версия упомянута как переделанная; добавлены раскрывающиеся таблицы «порог → доля стопов среди отрезанных» и «эффективность: net, R, WR, сделки».

Файл самодостаточный, открывается в браузере.

Исходник и скрипты сборки лежат на Mac владельца в `BBB_data/research/analysis/BTCUSDT.P/book_metrics_v6/treatise/almanac/`: `almanac.html`, `assemble.py`, `add_*.py`.
