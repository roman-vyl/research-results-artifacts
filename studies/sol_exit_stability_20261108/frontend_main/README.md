# SOL EMA200 Protected + TD

Два кандидата основной поверхности solusdt_p.ema200.w8_or_sp109_no_spot_5d.

| Вариант | Стек / лукбэк | SL / TP | Protected | TD T / D | Прогон |
| --- | --- | --- | --- | --- | --- |
| wide | 9 / 70 | 6 ATR / 4,5R | 1h ΔADX(14) ≥ 0,25 и DI по стороне позиции | 4 / 1,25R | run_30cf3f1a3bd34a91a7cecd98a0d641b5 |
| narrow | 4 / 240 | 6 ATR / 6R | 15m ΔADX(14) ≥ 23,5 и DI по стороне позиции | 4,5 / 1R | run_1180f8137a034ab6a48f2913187b2e88 |

У обоих касания без лимита, W8 OR SP109 без SPOT, начальный капитал $10 000, комиссии 0,04% на сторону. Protected выставляет стоп на цену входа со следующей свечи. TD включает Runner и отменяет initial TP, затем стоп следует за лучшей ценой с дистанцией D.

surface.manifest.json содержит текущий манифест основной поверхности с полной таблицей. candidates.manifest.json вместе с rows.csv образуют автономный проверочный срез двух добавленных строк. Файлы wide.manifest.json и narrow.manifest.json содержат полные запросы Research API. Файлы *.strategy.json — спецификации из записанных Engine-прогонов. Файлы *.runtime.off.json пригодны для Runtime с enabled=false.

В основной поверхности обе строки отмечены кандидатами, их сохранённые спецификации доступны через штатную кнопку To Runtime. Экспорт создаёт выключенный экземпляр. verification.json содержит идентификаторы кандидатов, прогонов и будущих экземпляров Runtime, а также результат сопоставления 217 сделок.

Манифесты проверены штатной материализацией Calculate. Спецификации выключенных экземпляров прошли загрузку штатным каталогом Runtime в отдельном временном каталоге.
